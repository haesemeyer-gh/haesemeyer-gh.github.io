datenschutzerklärung

ip adressen und weitere informationen, die benötigt werden, um anfragen über ein netzwerk zu bearbeiten, werden zwischengespeichert. der web-server speichert keine logs.

der büffler sammelt folgende daten, die für die funktionalität notwendig sind:

  • e-mail adresse, frei wählbarer anzeigename, berechtigungen und passwort hash der nutzer
  • zeitstempel des letzten logins (bzw. session-erstellung) der nutzer
  • name, mitglieder- und berechtigungsliste der teams
  • alle informationen der termine, die die nutzer angeben
  • die vollständige versionsgeschichte aller termine
  • subscription-daten für pushbenachrichtigungen von nutzern, die diese aktiviert haben
jegliche termindaten inklusive versionsgeschichte werden höchstens 4 monate gespeichert. nutzerdaten werden so lange gespeichert, wie das nutzerkonto besteht und werden unmittelbar auf maschinelle anfrage gelöscht.

der server wird leider auf microsoft azure gehostet. da es microsoft ist will es mir keine avv oder andere scheiß rechtliche dokumente geben also habt ihr pech gehabt. wenn ihr denkt, dass ihr bei microsoft datenschutz habt, ist eh vorbei.

wöchentliche e-mail digests über anstehende termine werden über smtp2go verschickt.

meinerseits werden ansonsten keine daten weitergegeben.

nutzer haben unter anderem das recht auf

  • auskunft darüber, welche daten gespeichert werden
  • eine vollständige und maschinenlesbare kopie ihrer daten
  • korrektur jeglicher daten
  • löschung ihrer daten und widerspruch gegen die weitere erhebung
grundsätzlich steht für alles eine api und/oder eine weboberfläche zur verfügung, falls nicht, siehe die kontaktmöglichkeiten.

jegliche änderungen, die rechtliches betreffen, werden sofort per e-mail an die zuletzt angegebene adresse aller nutzer kommuniziert.
